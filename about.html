A조 팀 소개 및 모험의 시작

"이 세계에는 포켓몬스터라 불리는 신비한 생명체와, Git으로 협업하는 6명의 개발자가 살고 있단다!"

1. 팀 소개 및 구성 배경

팀명: PokeDex

슬로건: "너로 정했다! 내 첫 번째 Git 협업 포트폴리오!"

오픈소스 SW 활용 수업을 통해 모인 윤하진(팀장), 허민재, 이예성, 김도영, 이재환, 이서준 6명의 팀원이 HTML5, CSS3, JavaScript 기반의 웹사이트 개발과 GitHub 실전 협업을 익히기 위해 결성한 팀입니다. 단순한 과제 수행을 넘어, 팀원 각자의 강점을 포켓몬 타입과 능력치로 표현한 '팀 포트폴리오 도감'을 제작하고 있습니다.

2. 연구소의 3대 핵심 목표

GOAL 01 · 도감 UI 구현

웹 표준 및 반응형 도감

백엔드 없이 순수 HTML5, CSS3, JavaScript만을 활용하여 PC·태블릿·모바일 어디서든 깔끔하게 보이는 포켓몬 도감 UI를 구축합니다.

GOAL 02 · 협업 마스터

Git & GitHub 협업 프로세스

main 직접 푸시를 금지하고 Issue 등록, feature/* 브랜치 분리, Pull Request 및 상호 코드 리뷰 과정을 철저히 준수합니다.

GOAL 03 · 역할 책임제

6인 분업과 유기적 통합

기획·저장소 관리, 검색·접근성, 포켓몬 도감·발표, 메인·소개·프로필, 공통 UI·FAQ, 반응형·JS 인터랙션까지 6인의 역할을 명확히 나누어 통합합니다.

3. 향후 활동 방향

  • 1단계 (기반 구축): GitHub 저장소(YunHj14/PokeDex) 세팅, 브랜치 전략 수립 및 5개 핵심 페이지(메인·팀 소개·팀원·포켓몬 도감·활동 기록) 구현
  • 2단계 (기능 및 디자인 고도화): 공통 헤더·푸터 적용, 반응형 레이아웃 최적화, 검색·필터 및 동적 JavaScript 인터랙션 연결
  • 3단계 (검수 및 GitHub Pages 배포): 웹 접근성 및 링크 오류 테스트 완료 후 GitHub Pages를 통해 웹사이트 공개 및 최종 시연
