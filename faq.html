조건에 맞는 질문이 없습니다. 다른 태그를 선택하거나 초기화해 주세요.

PokeDex는 어떤 사이트인가요?
#소개

오픈소스 SW 활용 수업에서 A조 6명이 함께 만드는 팀 포트폴리오 도감입니다. 팀 소개, 팀원별 역할과 프로젝트 정보를 확인할 수 있습니다.

팀원 소개는 어디에서 볼 수 있나요?
#소개 #이용방법

상단 메뉴의 팀원 도감에서 윤하진, 허민재, 이예성, 김도영, 이재환, 이서준의 소개와 담당 역할을 확인할 수 있습니다.

어떤 기술을 사용하나요?
#기술

HTML, CSS, JavaScript로 구성하는 정적 웹사이트입니다. Git과 GitHub를 이용해 작업을 나누고 변경 내용을 관리합니다.

FAQ의 답변은 어떻게 확인하나요?
#이용방법

질문을 클릭하면 답변이 펼쳐지고, 다시 클릭하면 접힙니다. 키보드의 Tab으로 질문을 선택한 후 Enter 또는 Space를 눌러도 됩니다.

메뉴를 눌렀는데 페이지가 열리지 않아요.
#오류 #이용방법

연결된 페이지가 아직 개발 중이거나 파일이 빠져 있을 수 있습니다. 다운로드한 HTML 파일과 css 폴더를 같은 프로젝트 폴더 구조로 유지해 주세요. 계속 문제가 생기면 문의 페이지로 알려 주세요.

오류나 개선 의견은 어디로 보내나요?
#문의

문의 페이지의 GitHub 링크를 이용해 주세요. 이미 등록된 문의를 확인하거나 로그인 후 새로운 Issue를 작성할 수 있습니다.

문의에 어떤 내용을 적으면 되나요?
#문의

문제가 발생한 페이지, 누른 버튼, 예상한 결과와 실제 결과를 적어 주세요. 기기와 브라우저 정보도 도움이 됩니다. 비밀번호나 개인 연락처는 적지 마세요.
